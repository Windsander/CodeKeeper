类型颜色来源示例 label
system● 橙黄固定根节点CodeKeeper-System

边类型（label）

  • system → project："contains"，系统包含项目。
  • system → agent_skill / profile："shared"，跨项目通用技能/画像。
  • project → topic："contains"，项目包含话题。
  • topic → episode / agent_case："contains"，话题包含记忆条目。
  • agent_skill → agent_case："derived_from"，技能由哪些 case 聚合而来（使用 source_case_ids）。
  • agent → episode / agent_case / agent_skill："authored"，Agent 是作者。
  • user → episode / profile："authored" / "has_profile"，用户是作者。
