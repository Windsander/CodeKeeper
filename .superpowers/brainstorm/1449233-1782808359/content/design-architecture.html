设计方案 1/4：架构 overview

Graph View + Progress View 双页签记忆可视化的整体数据流

架构图
Electron MemoryGraphPage
Graph View / Progress View 页签
↕ useIpc('memory.graph')
Daemon MemoryGraphHandler
聚合图、枚举 owner、调 EverOS /get
↕ HTTP /api/v1/memory/get
EverOS Server
按 (app, project, owner, kind) 返回条目

关键决策

  • 后端聚合：Daemon 负责把 EverOS 返回的扁平条目转换成 { nodes, edges }，前端只渲染。
  • 跨项目 + System 顶层：以 CodeKeeper-System 为根，下面挂每个项目；跨项目 skill / profile 挂到 System 下。
  • 写入侧修正 session 语义：Reviewer 按 MR、Maintainer 按 MR/discussion、Archiver 按 8h 窗口生成 sessionId，让话题层自然正确。
  • 历史数据不迁移：只展示 session 语义修复后写入的记忆。
  • 前端库：vis-network，与 EverOS Demo 一致。
