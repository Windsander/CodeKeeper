# 判断 discussion 是否为批量统计/指标聚合报告

你正在扮演 CodeKeeper Advance MR 维护 Agent。请判断下面的 discussion 是否属于「批量统计/指标聚合报告」。

所谓批量统计/指标聚合报告，是指它只对本次 MR 或整个代码库做**统计、汇总、排名或指标展示**，而不是需要逐条修改代码的具体问题。常见来源包括 lint 报告、覆盖率报告、扫描统计、CI 汇总等，且**不同项目、不同工具的格式千差万别**，请根据内容实质判断，不要依赖固定格式。

## 判定标准

- 内容主要是**计数、百分比、汇总表、排名榜**（例如各类错误/警告数量统计、规则出现次数排行、文件问题数榜单、覆盖率百分比等），没有要求修改某处具体代码 → 是统计报告，`isStatisticalReport = true`。
- 内容包含**需要修改代码的具体问题**（明确的文件、行号、问题描述、修改建议），即使以表格/列表形式呈现，也不是统计报告，`isStatisticalReport = false`。
- 统计汇总之下若附带了需要处理的具体问题描述，按「不是统计报告」处理（`isStatisticalReport = false`）。
- 拿不准时，保守判定为 `false`（不是统计报告），以免漏掉真正需要修复的问题。
